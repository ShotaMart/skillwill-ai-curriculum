Artificial Intelligence (AI)

მანქანის უნარი, მოახდინოს ადამიანური ინტელექტუალური ქცევის სიმულაცია — აღქმა, სწავლა და ამოცანების ავტონომიური გადაწყვეტა.

1950-იანი წლებიდან დღემდე
ქვედარგი

Machine Learning (ML)

ალგორითმები და სტატისტიკური მოდელები, რომლებიც სწავლობენ მონაცემებიდან მკაცრი წესების ხელით გაწერის გარეშე.

Deep Learning & ნეიროქსელები
დღევანდელი რევოლუცია

Generative AI & LLM

ტრანსფორმერული ნეიროქსელები, რომლებიც აგენერირებენ ახალ შინაარსს: ტექსტს, კოდს, გამოსახულებასა და აგენტურ ლოგიკას.

2022+ ეპოქა
ინტელექტუალური ქცევის 5 საკვანძო ნიშანი:
1. დასწავლა: გამოცდილებიდან შაბლონების ათვისება
2. მსჯელობა: ლოგიკური დასკვნების გამოტანა
3. პრობლემის გადაჭრა: ოპტიმალური გზის შერჩევა
4. აღქმა: მულტიმოდალური ანალიზი
5. ენა: ბუნებრივი ენის გენერაცია

AI პლატფორმების 4 კატეგორია — სად და როგორ ვიყენებთ?

სლაიდი 3 / 6
01

Consumer AI ჩატბოტები

ყოველდღიური ინდივიდუალური ამოცანები

მზა ვებ-აპლიკაციები სწრაფი კითხვა-პასუხისთვის, ტექსტების რედაქტირებისთვის, კვლევისა და იდეების გენერაციისთვის.

მაგალითები: ChatGPT Free/Plus, Claude.ai, Gemini Web
02

Enterprise Copilots

კორპორატიული სამუშაო გარემო

საოფისე პროგრამებში ჩაშენებული, უსაფრთხო ასისტენტები კომპანიის შიდა დოკუმენტებთან წვდომით (SSO, Audit, Data Privacy).

მაგალითები: Microsoft 365 Copilot, Google Workspace Gemini, ChatGPT Team/Enterprise
03

Cloud Developer Platforms

ინჟინრები, ანალიტიკოსები და API

დეველოპერული გარემო, სადაც სრულად კონტროლდება პარამეტრები (System Prompt, Temperature, JSON Mode, Function Calling).

მაგალითები: Google AI Studio, Anthropic Console, OpenAI Platform, Azure AI Foundry
04

Open-Weights / Local AI

სრული კონფიდენციალურობა და იზოლაცია

ღია მოდელები, რომლებიც ეშვება საკუთარ კომპიუტერზე ან ლოკალურ სერვერზე ინტერნეტის გარეშე, მონაცემთა 100% დაცვით.

მაგალითები: Meta LLaMA 3, DeepSeek-R1, Mistral, Ollama, LM Studio

მონაცემთა დაცვა — 3 „არასდროს“ წესი ორგანიზაციაში

სლაიდი 5 / 6
🛑 წესი 1

არასდროს გააგზავნო PII და საიდუმლოებები

  • ⚠️ პერსონალური მონაცემები: პირადი ნომრები, პასპორტის სკანები, სამედიცინო ჩანაწერები.
  • ⚠️ ფინანსები: საბანკო რეკვიზიტები, შიდა ბიუჯეტი და ინვოისები.
  • ⚠️ ტექნიკური: კომპანიის დახურული კოდი (Source Code) და API გასაღებები.
🛑 წესი 2

არ გამოიყენო კორპორატიულად Opt-Out-ის გარეშე

  • ⚠️ უფასო ჩატბოტები ნაგულისხმევად იყენებენ საუბრებს მოდელის შემდეგი წვრთნისთვის.
  • ⚠️ სავალდებულოა პარამეტრებში Model Training-ის გათიშვა (Data Opt-Out) პირველივე დღეს.
  • ⚠️ სამუშაო მონაცემებისთვის გამოიყენება მხოლოდ Enterprise / Zero-Data Retention პაკეტები.
🛑 წესი 3

არასდროს ენდო ფაქტებს ბრმად (გადამოწმება)

  • ⚠️ გენერაციული AI აგენერირებს ალბათურ ტექსტს და ხშირად დამაჯერებლად ჰალუცინირებს.
  • ⚠️ თარიღები, ციტატები, კანონის მუხლები და ციფრები ყოველთვის მოითხოვს პირველწყაროსთან შემოწმებას.
  • ⚠️ ადამიანი რჩება 100%-ით პასუხისმგებელი საბოლოო შედეგზე (Human-in-the-Loop).
