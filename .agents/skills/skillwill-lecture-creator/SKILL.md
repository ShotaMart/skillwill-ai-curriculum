# Skillwill Lecture & Presentation Creator Skill

ეს სქილი წარმოადგენს სავალდებულო საოპერაციო სტანდარტს Skillwill-ის სადიპლომო პროგრამის („შესავალი ხელოვნურ ინტელექტში“) ყველა ლექციისა და პრეზენტაციის მოსამზადებლად.

---

## 1. სასწავლო დროის ლოგიკური დეკომპოზიცია (Time Slicing)

- **ფუნდამენტური წესი**: თითოეული პრეზენტაცია ეკუთვნის მკაცრად **2-საათიან დამოუკიდებელ ლექციას** (50 წუთი თეორიული პრეზენტაცია + 70 წუთი პრაქტიკული ვორქშოპი).
- **4-საათიანი თემები**: იყოფა 2 დამოუკიდებელ 2-საათიან ლექციად ➔ **2 ცალკეული 10-სლაიდიანი პრეზენტაცია**.
- **6-საათიანი თემები**: იყოფა 3 დამოუკიდებელ 2-საათიან ლექციად ➔ **3 ცალკეული 10-სლაიდიანი პრეზენტაცია**.
- **დავალებების წესი**: პრეზენტაცია ეთმობა **მხოლოდ თეორიას, მენტალურ მოდელებსა და არქიტექტურას**. პრეზენტაციის სლაიდებში პრაქტიკული დავალება ან საშინაო დავალება **არ იწერება** (მასწავლებელი მას ცალკე ამზადებს).
- **სკრიპტების წესი**: პრეზენტაციის ჩანაწერებში (Notes) სალექციო სკრიპტი **არ იწერება** (`notes_text_frame` რჩება ცარიელი).

## 3. ვიზუალური დიზაინის 5 ურყევი წესი

### 1. შრიფტის სტანდარტი (100% ARIAL)
- **კატეგორიულად დაუშვებელია ნებისმიერი სხვა შრიფტი!**
- ყველა ელემენტზე (სათაურები, ქვესათაურები, კატეგორიები, ბარათები, ნომრები, ფორმულები, ცხრილები): `font.name = 'Arial'`.
- ტიპოგრაფიული იერარქია:
  - სლაიდის მთავარი სათაური: `30pt Arial Bold`
  - სექციის / ბარათის სათაური: `18-22pt Arial Bold`
  - მინი-ბარათის დასახელება: `13-16pt Arial Bold`
  - ძირითადი ტექსტი / აღწერა: `12-14pt Arial`
  - კატეგორიის წარწერა / თეგი: `11-13pt Arial Bold`

### 2. კუთხის არტეფაქტის აკრძალვა
- წითელი გეომეტრიული კუთხის გრაფიკა (`Freeform 3 & 4`) რჩება **მხოლოდ პირველ (სათაურის) და მე-10 (ბოლო) სლაიდებზე**.
- **შიდა სლაიდებზე (2–9) აკრძალულია ზედა მარჯვენა წითელი ბლოკის ჩასმა!** ზედა მარჯვენა კუთხე რჩება სუფთა.

### 3. ქვედა ფუტერის მოცილება
- შინაარსობრივ სლაიდებზე (2–9) **არ იწერება არანაირი ქვედა წარწერა** (არც საგნის სახელი, არც მოდულის ნომერი). ქვედა ზონა რჩება თავისუფალი.

### 4. ლოგოების სტანდარტი (512x512 Square RGBA Icons)
- **აკრძალულია განიერი ტექსტური Wordmark-ების ჩასმა!**
- ყველა ლოგო ინახება `assets/logos/` დირექტორიაში, როგორც **512x512 გამჭვირვალე კვადრატული PNG**:
  - ცენტრში მოთავსებულია მხოლოდ ბრენდის სიმბოლო (მაგ. Claude-ს 14-ქიმიანი ვარსკვლავი, Gemini-ს ნათება, Copilot-ის სპირალი, Meta-ს უსასრულობის მარყუჟი).
  - PPTX-ში ჩასმისას ყოველთვის გამოიყენება 1:1 პროპორცია (მაგ. `0.65" x 0.65"`, `1.5" x 1.5"`, `1.6" x 1.6"`).

### 5. ნულოვანი გადაფარვის მათემატიკური გეომეტრია (Zero-Overlap)
- ფონური კონტეინერის ფორმა (`MSO_SHAPE.ROUNDED_RECTANGLE`) არის მხოლოდ ვიზუალური ჩარჩო (`fill + border`) — მასში **ტექსტი არ იწერება** (`text_frame.text = ""`).
- შიდა ელემენტები (სათაური, ლოგო, ტექსტი) იქმნება დამოუკიდებელ ფიქსირებულ Y-კოორდინატებზე:
  - Header: `Y = 0.60" – 1.95"` (გამყოფი ხაზი `1.95"`)
  - ბარათები იწყება: `Y = 2.35"`
  - მინი-ბარათები: `Y = 5.25"`, `6.35"`, `7.45"` (თითოეულში ლოგო `Y + 0.15"`, ტექსტი `Y + 0.12"`).

### 6. ტერმინოლოგიის ორენოვანი სტანდარტი (Bilingual Terminology)
- **ცნობილი ინდუსტრიული ინგლისური ტერმინები არ ითარგმნება იზოლირებულად!**
- როდესაც გამოიყენება დამკვიდრებული ტექნოლოგიური ტერმინი, აუცილებლად იწერება **ინგლისური დასახელება**, ხოლო მის გვერდით **ფრჩხილებში ქართული განმარტება/თარგმანი**.
- მაგალითები:
  - `Supervised Learning (ზედამხედველობითი სწავლება)`
  - `Unsupervised Learning (ზედამხედველობის გარეშე სწავლება)`
  - `Reinforcement Learning (განმტკიცებითი სწავლება)`
  - `Train / Test Split (საწვრთნელი და სატესტო მონაცემები)`
  - `Overfitting (გადაზეპირება / მონაცემებზე გადამეტებული მორგება)`
  - `Generalization (განზოგადების უნარი)`
  - `Neuron (ხელოვნური ნეირონი)`
  - `Weights & Biases (წონები და გადახრები / კოეფიციენტები)`
  - `Layers (ფენები - Input, Hidden, Output)`
  - `Forward Pass (პირდაპირი გავრცელება / პროგნოზი)`
  - `Backpropagation (შეცდომის უკუგავრცელება)`
  - `Loss Function (შეცდომის შეფასების ფუნქცია)`
  - `CPU vs GPU (ცენტრალური vs გრაფიკული პროცესორი)`

### 7. შიდა მეტა-ინსტრუქციების მკაცრი აკრძალვა (No Internal Meta-Text)
- **სლაიდების ტექსტში კატეგორიულად აკრძალულია შიდა სამუშაო ინსტრუქციების ჩაწერა!**
- აკრძალულია ისეთი ფრაზების გამოჩენა, როგორიცაა: „0-ლეველის მენტალური მოდელი“, „სტუდენტებისთვის განმარტება“, „პედაგოგიური შენიშვნა“ და ა.შ.
- სლაიდზე იწერება მხოლოდ ბუნებრივი, სტუდენტისთვის განკუთვნილი სათაური: **„💡 მთავარი არსი (მარტივი ანალოგია):“** ან **„💡 როგორ წარმოვიდგინოთ ეს მარტივად?“**.
